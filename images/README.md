# Images

Drop your images into this folder using **exactly these file names**. Until a file is added, a soft gradient is shown in its place, so the site always looks finished.

| File name | Where it appears | Recommended size |
|---|---|---|
| `logo.png` | Header, next to the business name (transparent PNG) | 200 × 80 |
| `favicon.png` | Browser tab icon | 64 × 64 |
| `hero.jpg` | Full-screen top banner (calm scene: water, sky, nature, therapy room) | 1920 × 1080 |
| `about.jpg` | "Meet your therapist" portrait | 800 × 1000 (portrait) |
| `service-anxiety.jpg` | Anxiety & Stress card | 800 × 500 |
| `service-smoking.jpg` | Quit Smoking card | 800 × 500 |
| `service-weight.jpg` | Weight Management card | 800 × 500 |
| `service-confidence.jpg` | Confidence card | 800 × 500 |
| `service-sleep.jpg` | Sleep & Insomnia card | 800 × 500 |
| `service-phobias.jpg` | Fears & Phobias card | 800 × 500 |
| `testimonial-1.jpg` … `testimonial-3.jpg` | Client photos in reviews (optional) | 200 × 200 (square) |

Tips: save photos as JPG at ~80% quality and keep each under ~400 KB so the page loads fast. Only use client photos with their permission.
